# 墨排 · Markdown 排版

墨排是一个本地优先的 Markdown 排版工具。它只做一件事：把你写好的 Markdown，变成可以直接粘进微信公众号后台的成稿。

左边照常写 Markdown，右边就是最终的成稿样式，点一下就能复制。

## 为什么需要它

公众号后台的编辑器不适合写技术文章：代码块、表格、公式、脚注都不好处理，排版靠手点。而用现成的 Markdown 编辑器写，复制过去的样式又常在微信里走样——行距、字重、引用块的边线，总有一两处对不上。

墨排把这两步接起来：左边照常写 Markdown，右边实时预览成稿样式，点一下就能复制，不用登录，也不依赖自有服务端。

## 三条底线

- **草稿不离开浏览器**：文章只存在你自己的浏览器里，没有账号、没有云端、没有分享链接。关掉页面之前它就在那里，关掉之后也还在。
- **打开就能用**：不需要注册，不需要授权，不弹引导。第一次打开看到的就是编辑器，第二秒就能开始写字。
- **预览即承诺**：预览里看到的样式，就是粘进公众号之后得到的样式。

## 功能

### 写作

- **Markdown 编辑器**：标题、列表、表格、代码块、引用、脚注、公式、提示块等写法都支持，输入时有语法高亮。
- **斜杠命令**：行首输入 `/` 快速插入标题、列表、表格、代码块、公式等片段，`Tab` 在待填的位置之间切换，也支持中文，比如输入 `/表格`。
- **编辑工具条**：加粗、斜体、下划线、删除线、标题、列表、引用、代码块、链接、分割线，一键插入。
- **撤销 / 重做**：按钮和快捷键都可以。
- **实时预览**：左边写，右边同步显示最终排版，滚动位置联动。

### 主题与排版

- **9 套文章主题**：墨影、松间、潮汐、暖沙、樱雾、紫藤、琥珀、报刊、素白，默认「素白」。
- **主题面板**：切换时即时预览实际排版效果，确认后再应用到文章。
- **深色模式**：界面与文章预览都有对应的深色配色。

### 发布

- **复制到公众号**：样式随内容一起带走，粘贴即成型；表格、代码块、任务列表和公式都能正常显示。
- **复制 HTML**：输出干净的 HTML 片段，方便贴到其他编辑器或平台。
- **导出长图**：按手机宽度排版后导出为图片，适合图片消息。
- **导入 / 导出 Markdown**：支持本地 `.md` 文件读写。

### 其他

- **草稿自动保存**：刷新页面后会自动恢复文章、主题和发布偏好。
- **手机可用**：编辑与预览可切换，工具栏横向滚动。
- **图片用链接引入**：不需要图床配置。

## 三分钟上手

1. 把 Markdown 粘进左侧稿面，或直接在稿面里写。
2. 在「主题」里挑一套样式，右侧实时预览会跟着变。
3. 点「文件 → 复制到公众号」，去后台粘贴即可。

## 运行

```bash
npm install
npm run dev
```
